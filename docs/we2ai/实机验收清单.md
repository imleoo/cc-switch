## 1A. 壳与隔离（P0）

| # | 平台 | 步骤 | 通过标准 |

| 1A.5 | macOS / Windows | CC Switch 开启代理接管后启动并退出 WE2AI，前后计算 `~/.claude/settings.json` 与 `~/.codex/config.toml` 的哈希 | 两个文件逐字节不变 |
